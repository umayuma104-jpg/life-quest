# Life Quest ⚔️

毎日のタスク（クエスト）をこなして経験値を貯め、レベルを上げていく「人生アップグレード」ゲーム。
運動・早起き・読書・瞑想などの習慣で、生活に規律を与えることが目的です。

## 遊び方

`index.html` をブラウザで開くだけでも遊べます。
PWA に対応しているので、HTTPS で公開するとスマホのホーム画面にインストールでき、オフラインでも動きます。

### スマホにインストールする（GitHub Pages）

1. このブランチを `main` にマージする
2. GitHub のリポジトリ → **Settings → Pages** → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/life-quest/` で公開される
4. スマホでそのURLを開いて
   - **iPhone**: Safari の共有ボタン →「ホーム画面に追加」
   - **Android**: Chrome の「アプリをインストール」、またはアプリ内 設定タブの「📲 ホーム画面に追加」

### PWA の構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `css/style.css` | 画面とドット絵風デザイン |
| `js/app.js` | ゲームの処理（記録・計算・しつもん・通知・バックアップ） |
| `js/sprites.js` | ドット絵素材（主人公・ボス10体・クエストアイコン） |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |
| `sw.js` | Service Worker。オフライン用キャッシュと通知 |
| `icons/` | アプリアイコン（通常・maskable・Apple 用） |

アプリを更新したときは `sw.js` の `VERSION` を上げると、利用者側のキャッシュが新しいものに入れ替わります。

## ルール

| 要素 | 内容 |
| --- | --- |
| はじめての しつもん | 目的・運動習慣・使える時間・起床時刻を聞いて、おすすめのクエストを提案。設定からいつでもやり直せる |
| クエストの種類 | **やった/やってない**、**回数・時間**（＋/−ボタンで記録）、**起床時刻**（目標時刻までなら満額、30分以内の遅れは半分） |
| クエスト枠 | 最初は3つ。Lv3・5・8・12・16・20・25で1つずつ増える（最大10） |
| 能力値 | 各クエストは STR / INT / MND / VIT のどれかを伸ばす |
| 達成日 | その日のクエストの3分の2以上をクリアすると「達成日」。HP+10 |
| 連続ボーナス | 達成日が続くごとにEXP +5%（最大 ×1.5） |
| ❄ こおりのおまもり | 連続3日ごとに1個獲得。未達成の日に自動で1個消費し、HPダメージと連続記録リセットを防ぐ |
| HP | 最大100。❄がないと未達成で -15、何も記録しない日は -25。予告がクエスト画面に出る |
| 戦闘不能 | HPが0になると、今のレベルで貯めたEXPの半分を失いHP全回復（レベルは下がらない） |
| 週ボス | 毎週月曜に出現（10種類）。その週に稼いだEXPがダメージになり、倒すと報酬EXP。倒したボスは「まもの ずかん」に載る |
| レベルアップ | 称号・装備（主人公のドット絵が変わる）・ウィンドウの色が変わる。効果音・振動・Xでシェア |
| 曜日別クエスト | クエストごとに実施曜日を設定。予定ゼロの日は「やすみ」でペナルティなし |
| リマインダー | 朝・夜の通知 ＋ 毎日のリマインダーをカレンダーに登録する .ics 出力 |
| バックアップ | JSONファイルに保存/復活。7日バックアップしていないとお知らせが出る |
| 日付の切り替え | 午前3時（夜更かしした分は前日扱い） |
