# Life Quest ⚔️

毎日のタスク（クエスト）をこなして経験値を貯め、レベルを上げていく「人生アップグレード」ゲーム。
運動・早起き・読書・瞑想などの習慣で、生活に規律を与えることが目的です。

## 遊び方

`index.html` をブラウザで開くだけでも遊べます。
PWA に対応しているので、HTTPS で公開するとスマホのホーム画面にインストールでき、オフラインでも動きます。

### スマホにインストールする（GitHub Pages）

1. このブランチを `main` にマージする
2. GitHub のリポジトリ → **Settings → Pages** → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/fitness-app/` で公開される
4. スマホでそのURLを開いて
   - **iPhone**: Safari の共有ボタン →「ホーム画面に追加」
   - **Android**: Chrome の「アプリをインストール」、またはアプリ内 設定タブの「📲 ホーム画面に追加」

### PWA の構成

| ファイル | 役割 |
| --- | --- |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |
| `sw.js` | Service Worker。オフライン用キャッシュと通知 |
| `icons/` | アプリアイコン（通常・maskable・Apple 用） |

アプリを更新したときは `sw.js` の `VERSION` を上げると、利用者側のキャッシュが新しいものに入れ替わります。

## ルール

| 要素 | 内容 |
| --- | --- |
| クエストの種類 | **チェック**（やった/やってない）、**回数・量**（目標値に対する割合でXP）、**起床時刻**（目標時刻までなら満額、30分以内の遅れは半分） |
| 能力値 | 各クエストは STR(体力) / INT(知力) / MND(精神) / VIT(生活) のどれかを伸ばす |
| 達成日 | その日のクエストの70%以上をクリアすると「達成日」 |
| 連続ボーナス | 達成日が続くごとにXP +5%（最大 ×1.5）。1日でも空くとリセット |
| レベル・称号 | XPでレベルアップ。Lv3・5・8…50 で称号を獲得 |
| HP | 最大100。達成日で+10回復。未達成の日は -15、何も記録しない日は -25 |
| 戦闘不能 | HPが0になると、今のレベルで貯めたXPの半分を失いHP全回復（レベルは下がらない） |
| ❄️ 凍結アイテム | 連続3日ごとに1個獲得。未達成の日に自動で1個消費し、HPダメージと連続記録リセット（＝ボーナス消失）を防ぐ |
| 曜日別クエスト | クエストごとに実施曜日を設定。予定ゼロの日は「休息日」でペナルティなし |
| 週ボス | 毎週月曜に出現。その週に稼いだXPがダメージになり、倒すと報酬XP（HPの30%） |
| リマインダー | 朝・夜のブラウザ通知（ページを開いている間）＋ 毎日のリマインダーをカレンダーに登録する .ics 出力 |
| 日付の切り替え | 午前3時（夜更かしした分は前日扱い） |

クエストは設定タブで自由に追加・編集・並べ替えできます。
データはブラウザの localStorage に保存され、JSON でエクスポート/インポートできます。
