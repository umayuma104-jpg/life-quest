# Life Quest ⚔️

毎日のタスク（クエスト）をこなして経験値を貯め、レベルを上げていく「人生アップグレード」ゲーム。
運動・早起き・読書・瞑想などの習慣で、生活に規律を与えることが目的です。

## 遊び方

`index.html` をブラウザで開くだけでも遊べます。
PWA に対応しているので、HTTPS で公開するとスマホのホーム画面にインストールでき、オフラインでも動きます。

### スマホにインストールする（GitHub Pages）

1. このブランチを `main` にマージする
2. GitHub のリポジトリ → **Settings → Pages** → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/life-quest/` で公開される
4. スマホでそのURLを開いて
   - **iPhone**: Safari の共有ボタン →「ホーム画面に追加」
   - **Android**: Chrome の「アプリをインストール」、またはアプリ内 設定タブの「📲 ホーム画面に追加」

### PWA の構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `css/style.css` | 画面とドット絵風デザイン |
| `js/app.js` | ゲームの処理（記録・計算・しつもん・通知・バックアップ） |
| `js/sprites.js` | ドット絵素材（主人公・ボス10体・アイコン） |
| `js/catalog.js` | 選べるクエストの一覧（目標・EXP・おすすめの条件） |
| `js/gear.js` | 装備・アイテム・ガチャのデータ（名前・値段・効果・確率） |
| `manifest.webmanifest` | アプリ名・アイコン・全画面表示の設定 |
| `sw.js` | Service Worker。オフライン用キャッシュと通知 |
| `icons/` | アプリアイコン（通常・maskable・Apple 用） |

アプリを更新したときは `sw.js` の `VERSION` を上げると、利用者側のキャッシュが新しいものに入れ替わります。

## ルール

| 要素 | 内容 |
| --- | --- |
| 最初の質問 | 目的・運動習慣・使える時間・起床時刻から、おすすめのクエストを提案。メニューからいつでも答え直せる |
| クエスト | 筋トレ・有酸素・ストレッチ・学び・生活の約60種から選ぶ（自作はなし）。道具が必要な種目やきつい種目は、初心者のおすすめには出ない |
| 目標とEXP | 回数・時間は適性（運動習慣・使える時間）の範囲内でだけ変更できる。EXPは回数に比例して自動で決まる。起床・就寝の時刻は自由 |
| クエスト枠 | 最初は3つ。Lv3・5・8・12・16・20・25で1つずつ増える（最大10） |
| 達成 | その日のクエストの3分の2以上をクリアすると達成。HP+10 |
| 連続ボーナス | 達成が続くごとにEXP +5%（最大 ×1.5） |
| ❄ 氷のお守り | 3日連続で達成するごとに1個獲得。未達成の日に自動で1個使い、HPダメージと連続記録のリセットを防ぐ |
| HP | 最大100。❄がないと未達成で −15、記録なしで −25。HP 0で戦闘不能（今のレベルで貯めたEXPの半分を失う） |
| 週ボス | 全20体。毎週月曜に弱い順に1体ずつ出現し、週を重ねるほどHPと報酬が上がる（一巡すると強化版）。その週に稼いだEXPがダメージになる。倒したボスは魔物図鑑に載る |
| 今日のボーナス | 毎日クエストの1つがEXP2倍 |
| 会心の一撃 | クエスト完了時に15%の確率でボスへのダメージ2倍 |
| 実績 | 連続記録・達成日数・全クリア・ボス討伐・早起き・累計回数・レベル・装備収集の25個。達成するとゴールド |
| 見た目 | 髪型5種・髪色8色・肌の色3色から選べる（メニュー／ステータス） |
| ジェム💎 | 達成した日5・ボス討伐30・実績20・レベルアップ10。ガチャに使う |
| ガチャ | 1回50💎・10連450💎（★4以上1つ確定）。★5 3%・★4 17%・★3 80%。80回で★5確定。重複はジェムに変換。提供割合は画面で確認できる |
| ガチャ限定装備 | 炎の魔導士（火傷）・毒牙の暗殺者（毒・会心）・氷竜の騎士（ボス討伐で❄・大幅防御）の3セット×6部位。3部位・6部位でセット効果、6部位でオーラ |
| アイテム | 回復薬（HP+30）・爆弾（ボスに最大HPの20%）・経験の書（その日のEXP×1.5）・氷のお守り（❄+1）。ショップやガチャで入手し、右上の👜から使う |
| 戦闘画面 | クエスト画面で主人公とボスが向き合う。記録すると主人公が斬りかかり、ダメージの数字・会心の演出・討伐の演出が出る。背景はボスごとに4種類 |
| チュートリアル | 最初の質問のあと、画面の要所を光らせて8ステップで説明。メニューからいつでも見直せる |
| ペット | Lv5で「ぷちスライム」が仲間になる。全7種（攻撃型は主人公の攻撃に追撃、支援型はEXP・ゴールド・会心・毎日回復、守り型は防御）。餌（干し肉・魔法のクッキー・竜の果実）やクエストで経験値がたまりLv30まで成長。首飾りと帽子を装備でき、見た目にも反映 |
| ペットガチャ | 1回500G／30💎、10回4500G／270💎。ペット8%・ペット装備22%・餌70%。40回でペット確定。重複は餌に変換 |
| 餌の入手 | レベルアップごとに干し肉×2（5の倍数で竜の果実）、ショップ、ペットガチャ |
| 今週・今月の目標 | 今週は今のクエストから3つ自動で選ばれる（各100G・10💎）。今月は「達成20日」「ボス討伐3体」（各400G・40💎） |
| 昨日の記録 | 記録し忘れた昨日の分を、週に2回まで追加・修正できる |
| 文字の大きさ | 標準・大・特大から選べる |
| 課金 | ジェム・ゴールドのパックを表示（購入は準備中。ログインと決済の仕組みが必要） |
| レベルアップ | 称号と枠の色が変わる。ボーナス50G |
| ゴールド | 獲得EXPの半分＋達成で20G＋ボス討伐で100G〜＋レベルアップで50G＋実績の報酬 |
| ショップ・装備 | 兜・鎧・レギンス・ブーツ・剣・盾の6部位。それぞれ初期装備＋3段階（革・銅 → 鉄 → 騎士）。兜・ブーツ・剣はボスへのダメージ増、鎧・レギンス・盾は最大HP増や被ダメージ軽減。試着でき、装備すると主人公の見た目が変わる。付け替えはその日から有効 |
| お知らせ | 右上の📬に、前回からの出来事・レベルアップ・バックアップのおすすめが届く |
| 日付の切り替え | 午前3時 |
